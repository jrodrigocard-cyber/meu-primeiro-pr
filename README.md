# meu-primeiro-pr
Repositorio de pratica para meu primeiro Pull Request

## Projetos locais com memória, armazenamento e skills

- `template/` — esqueleto: `CLAUDE.md` (memória), `.claude/skills/` (skills), `data/` (armazenamento local), `src/`.
- `./novo-projeto.sh nome [destino]` — cria um projeto novo a partir do template (padrão: `~/projetos/nome`).

Skills pessoais (para todos os projetos): `~/.claude/skills/`. Memória global: `~/.claude/CLAUDE.md`.
