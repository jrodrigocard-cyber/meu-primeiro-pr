# meu-primeiro-pr

Repositório de prática para o meu primeiro Pull Request no GitHub.

## Objetivo

Este repositório serve como exercício para aprender o fluxo de contribuição via Git e GitHub:
criar uma branch, fazer uma alteração, abrir um Pull Request e revisá-lo.

## Como contribuir

1. Crie uma branch a partir da `main`.
2. Faça sua alteração.
3. Abra um Pull Request descrevendo o que mudou e por quê.
